# Vanilla Advanced Trims (Minecraft 26.3) — Project Rules

## ⚠️ ВЕРСИЯ MINECRAFT: 26.3 (НЕ ОПЕЧАТКА!)

* **Критическое правило для AI:** Проект работает строго на **Minecraft 26.3**.
* **Это НЕ опечатка 1.20.x, 1.21.x или 1.26.x!** В проекте используется официальная ветка нумерации `26.3`.
* **Запрещено** «исправлять» 26.3 на 1.20/1.21/1.26 в диалогах, документации, коде, конфигах и датапаках.
* Все стандарты сериализации (датапаки, рецепты, компоненты DataComponents, формат Registry) должны строго соответствовать спецификации **26.3** (в частности: результат рецепта не может быть `minecraft:air`, ингредиенты объявляются плоским списком строк `["minecraft:..."]`).
